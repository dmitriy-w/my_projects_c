# Simple TCP Echo Server & Client

Учебный проект по созданию классического сетевого эхо-сервера и клиента на чистом Си, разрабатываемый по канонам системного программирования UNIX (на основе 5-й главы книги У. Стивенса).

## Обзор проекта
Проект направлен на детальное изучение низкоуровневой физики сетевого взаимодействия. Программа реализует базовый механизм обмена данными по протоколу TCP: клиент подключается к серверу, отправляет текстовую строку, а сервер принимает её и возвращает обратно («эхо»).

Данный сетевой каркас является фундаментальной базой. В будущем, после стабилизации текущего кода, на его основе будет развернут учебный исследовательский прототип утилиты удаленного администрирования.

##️ Текущий статус разработки
Проект собирается итеративно, шаг за шагом:
* **Спринт 1 (Текущий):** Развернута низкоуровневая инициализация сетевого стека в файле `rat_server.c` (в будущем — серверная часть). Реализовано создание слушающего дескриптора сокета (`socket()`), заполнение сетевых структур ОЗУ (`sockaddr_in`) и привязка к управляющему порту (`bind()`) с полной ручной обработкой системных ошибок ядра ОС.
* **Спринт 2 (В планах):** Перевод сервера в режим прослушивания очереди (`listen()`) и фиксация входящих сетевых сессий через системный вызов `accept()`.
* **Спринт 3 (В планах):** Разработка клиентской части эхо-системы для обмена сообщениями через сетевые дескрипторы.

# Crypto Vault (XOR String Cipher in Heap)

Учебный проект по системному программированию и информационной безопасности на языке Си.

## Что реализовано:
- **Безопасное выделение памяти:** Строки копируются в Кучу (Heap) с жестким контролем границ и выделением памяти под терминирующий ноль (`len + 1`).
- **Защита от переполнения:** Реализована итеративная очистка буфера `stdin` (потока ввода), предотвращающая логические сбои при вводе избыточных данных.
- **Побитовая криптография:** Написан кастомный движок XOR-шифрования строк с использованием оператора `^`.
- **ИБ-патчи:** Реализовано принудительное освобождение памяти (`free`) и зануление указателей (`NULL`) для защиты от уязвимостей типа Use-After-Free.

## Как запустить:
gcc crypto_vault.c -o vault && ./vault

# In-Memory Payload Decryptor & Stub Prototype

Облегченный прототип загрузчика (Stub) на чистом Си, демонстрирующий базовые концепции обхода сигнатурного анализа (AV/EDR evasion) и безопасного управления динамической памятью.

## 🩻 Обзор проекта
Проект реализует концепцию **In-Memory Execution**, которая активно исследуется в сфере кибербезопасности и защиты программного обеспечения от реверс-инжиниринга. 

Зашифрованная полезная нагрузка (Payload) хранится в секции данных бинарного файла (`.rodata`) в виде шестнадцатеричного массива (Hex). При запуске программа выделяет память в Куче (Heap), расшифровывает данные непосредственно в ОЗУ, имитирует выполнение и производит гарантированную зачистку следов перед выходом.

## 🛠️ Реализованные ИБ-концепции и технологии
* **Обход статического анализа (Static Evasion):** Исходная строка обфусцирована с помощью побитовой операции XOR с фиксированным 8-битным ключом (`0x5A`). Стандартные утилиты статического анализа (например, `strings`) не способны обнаружить присутствие строки в скомпилированном бинарнике.
* **Безопасная аллокация (Heap Management):** Динамическое выделение памяти через `malloc()` с обязательной валидацией указателя на `NULL` для предотвращения падения процесса.
* **Анти-форензика (Wiping):** Принудительное затирание расшифрованных данных нулями (`0x00`) с помощью функции `memset()` строго *перед* вызовом `free()`. Это предотвращает возможность извлечения конфиденциальной информации через дампы оперативной памяти (*Heap Inspection*).

## 🚀 Сборка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com
cd in-memory-stub-crypter
```

2. Скомпилируйте проект с помощью GCC:
```bash
gcc stub_crypter.c -o stub
```

3. Запустите исполняемый файл:
```bash
./stub
```
